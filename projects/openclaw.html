The Workspace Escape

Image-Tool Path Resolution

The image tool resolved user paths against process.cwd() instead of the agent's workspace — so reads could land outside the directory the allowlist was written to protect. My fix resolves paths against the agent workspace root, preserves the allowlist's security semantics, and ships with regression coverage so it stays fixed.
