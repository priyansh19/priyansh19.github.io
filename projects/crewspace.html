FILE 01 — THE MISSION

AN ORG CHART THAT EXECUTES ITSELF

Most "multi-agent" demos are a group chat with extra steps. CrewSpace asks the harder question: what if a company's entire operating structure — hierarchy, delegation, hiring, approvals — was software?

You hand the platform a goal. A CEO agent decomposes it into domain subtasks, routes them to specialist agents, and when the org lacks a capability, it proposes a new hire — a fresh specialist spun up with its own role, memory, and workspace permissions. Like JARVIS running Stark Industries: autonomous where it's safe, asking the human where it matters.

"Anyone can spawn agents. CrewSpace runs a company."

  • FILE SNAPSHOT
  • Founder-led — HITL approval workflows
  • Per-agent memory — persistent across sessions
  • A2A + group chat — built-in comms layer
  • Workspaces — shared files, scoped permissions
  • Terminal ops — integrated & reviewable
  • Open source — full build on GitHub
FILE 02 — CHAIN OF COMMAND

FROM ONE GOAL TO A WORKING COMPANY

01

Goal Intake

You give the company one objective. The CEO agent breaks it into domain subtasks — engineering, research, content, ops — each with a scope and an owner.

02

Delegation

Subtasks route to specialist agents by domain. Each specialist works inside its own workspace with scoped file permissions — no agent touches what it shouldn't.

03

The Hiring Loop

Missing a capability? The CEO proposes a new hire. You approve, and a new specialist joins the org with its own role, memory, and permissions.

04

Coordination

Agents collaborate over agent-to-agent and group chat. Consequential actions flow through approval workflows, so a human signs off before anything irreversible happens.

05

Delivery

Work lands on real-time task boards; the founder dashboard tracks every agent, task, and conversation — and the interactive 3D office lets you literally walk the floor.
