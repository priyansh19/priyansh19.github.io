Governance

Human-in-the-loop

Not every decision should be automated. Approval gates put humans back in control for high-impact actions — without slowing down routine work.

Approval Gate Types

Configure gates for the actions that matter most.

Budget Override

Any action that would exceed a team's monthly budget requires explicit human approval.

Agent Hiring

Adding a new agent to the company org chart requires approval from the company operator.

Strategy Change

Modifying company goals or strategic direction triggers an approval gate before execution.

Sensitive Access

Actions affecting secrets, credentials, or user data require board-level approval.

Approval Lifecycle

From request to resolution

Agent Requests

Agent detects a gated action and submits an approval request with full context.

Operator Notified

Board operator receives a notification with the request details and rationale.

Decision Made

Operator approves or rejects with optional feedback. Decision is logged.

Action Executed

If approved, the agent proceeds. If rejected, the agent receives guidance.
